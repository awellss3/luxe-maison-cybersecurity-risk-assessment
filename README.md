# Luxe Maison — Cybersecurity Risk Assessment

## Project Overview

Luxe Maison is a simulated luxury beauty e-commerce company created for a cybersecurity risk assessment project.

This project evaluates common cybersecurity risks that could affect an online beauty retailer, including phishing, account compromise, customer information exposure, third-party vendor incidents, cloud security risks, and business disruption.

The assessment applies cybersecurity risk management concepts and the **NIST Cybersecurity Framework (CSF) 2.0** to identify risks and recommend practical security controls.

> **Disclaimer:** Luxe Maison is a simulated business scenario created for educational and portfolio purposes. It is not an assessment of an actual company.

---

## Objectives

The goals of this project were to:

* Identify cybersecurity risks affecting a beauty e-commerce environment
* Evaluate potential business impact and likelihood
* Prioritize major security risks
* Recommend appropriate mitigation strategies
* Apply the NIST Cybersecurity Framework (CSF) 2.0
* Demonstrate foundational Governance, Risk, and Compliance (GRC) skills

## Key Risks Identified

| Risk                            | Potential Impact                            |
| ------------------------------- | ------------------------------------------- |
| Phishing & Social Engineering   | Credential theft and unauthorized access    |
| Customer Account Compromise     | Account takeover and customer trust issues  |
| Customer Information Exposure   | Privacy and regulatory concerns             |
| Third-Party Vendor Incident     | Exposure through external service providers |
| Cloud Security Misconfiguration | Unauthorized access or data exposure        |
| Business Disruption             | Loss of availability and revenue            |

## NIST CSF 2.0 Alignment

The assessment uses the six functions of the NIST Cybersecurity Framework 2.0:

* **Govern** — Establish cybersecurity governance, policies, and risk management practices
* **Identify** — Identify assets, risks, vulnerabilities, and business impacts
* **Protect** — Implement safeguards such as MFA, access controls, and security awareness training
* **Detect** — Monitor for suspicious activity and potential security incidents
* **Respond** — Establish procedures for containing and managing cybersecurity incidents
* **Recover** — Restore systems and operations following an incident

---

## Recommended Security Controls

Key recommendations include:

* Multi-factor authentication (MFA)
* Role-based access control (RBAC)
* Employee security awareness and phishing training
* Strong password and account security policies
* Vendor risk assessments
* Cloud security configuration reviews
* Logging and security monitoring
* Incident response procedures
* Data protection and backup strategies
* Regular vulnerability assessments
