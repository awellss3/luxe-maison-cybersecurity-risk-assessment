# Luxe Maison Beauty — Cybersecurity Risk Assessment

## Project Overview

**Luxe Maison Beauty** is a fictional beauty e-commerce company created for an independent cybersecurity portfolio project.

This project evaluates common cybersecurity risks affecting a beauty e-commerce environment, with a focus on **Governance, Risk, and Compliance (GRC)**, risk management, security controls, and the protection of customer and business information.

The assessment uses the **NIST Cybersecurity Framework (CSF) 2.0** to organize identified risks and recommended security improvements.

## Objectives

* Identify key cybersecurity risks within a beauty e-commerce environment
* Assess the potential impact and likelihood of identified threats
* Map cybersecurity risks to the NIST CSF 2.0
* Recommend practical security controls and mitigation strategies
* Evaluate third-party and cloud security risks
* Develop an incident-response scenario involving employee phishing
* Demonstrate foundational GRC and cybersecurity risk-management skills

## Key Risks Identified

The assessment focuses on:

* **Phishing & Social Engineering** — Employees may be targeted through fraudulent emails or messages.
* **Account Compromise** — Stolen credentials could provide unauthorized access to customer or business accounts.
* **Customer Data Exposure** — Sensitive customer information could be exposed through a security incident.
* **Third-Party Security Incidents** — Vendors and service providers may introduce additional cybersecurity risks.
* **Cloud Misconfiguration** — Improperly configured cloud services could expose systems or data.
* **Business Disruption** — Cybersecurity incidents could interrupt e-commerce operations and affect business continuity.

## Framework Used

### NIST Cybersecurity Framework 2.0

The project maps identified risks and security recommendations across the NIST CSF 2.0 functions:

| Function     | Application                                                                       |
| ------------ | --------------------------------------------------------------------------------- |
| **Govern**   | Establish cybersecurity policies, responsibilities, and risk-management processes |
| **Identify** | Identify assets, vulnerabilities, threats, and business risks                     |
| **Protect**  | Implement access controls, security awareness training, MFA, and other safeguards |
| **Detect**   | Monitor for suspicious activity and potential security incidents                  |
| **Respond**  | Establish procedures for containing and managing cybersecurity incidents          |
| **Recover**  | Restore operations and improve resilience following an incident                   |

## Risk Assessment

A qualitative risk assessment was used to evaluate identified threats based on factors such as:

* Likelihood
* Potential business impact
* Customer impact
* Operational disruption
* Security exposure

The assessment prioritizes risks that could significantly affect customer information, business operations, or the organization's overall security posture.

## Security Recommendations

Recommended controls include:

* Multi-factor authentication (MFA)
* Employee security awareness and phishing training
* Role-based access control
* Strong password and authentication policies
* Vulnerability management
* Cloud security configuration reviews
* Third-party vendor risk assessments
* Security monitoring and logging
* Incident-response procedures
* Data protection and access controls
* Regular security policy reviews

## Third-Party & Cloud Risk

Because e-commerce organizations often depend on external vendors, payment services, cloud platforms, and other technology providers, third-party security is an important part of the assessment.

Recommended practices include:

* Vendor security assessments
* Contractual security requirements
* Access reviews
* Monitoring of third-party integrations
* Cloud configuration reviews
* Least-privilege access
* Incident notification procedures

## Incident Response Scenario

The project includes a simulated employee phishing incident in which an employee interacts with a malicious message.

The scenario demonstrates how an organization could:

1. Identify the suspicious activity
2. Contain the affected account
3. Investigate the incident
4. Assess potential data exposure
5. Reset credentials and strengthen authentication
6. Communicate with relevant stakeholders
7. Document lessons learned
8. Improve security controls to reduce future risk
